# Requirements

1. Python
2. Super basic knowledge in directories

# Steps

1. Open your Twitter Bookmarks and **DO NOT scroll down**.  
2. Zoom out as much as you can (Ctrl + Scroll Wheel).  
3. Open Console (Ctrl + Shift + I), copy the JS file, and paste it in the console.  
4. Let it run for a while (more bookmarks → more time).  
   - After it finishes, it should download a text file in the Downloads folder.  
5. Move the text file to this folder.  
6. Run the Python command and follow its instructions:  
   - Enter the file path.  
   - Enter the file format (`png` or `jpg`).  
7. Let it run.  
8. Do what you want with the images.
